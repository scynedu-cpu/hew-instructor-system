# 작업지시서 #010-1 완료보고 — 대시보드에 누락서류·만료 D-day 표시 추가

- 일자: 2026-09-12
- 결과: **완료** (완료기준 5항목 전부 실제 데이터로 브라우저 검증, #010 회귀 없음)

---

## 1. 구현 내용

[강사 현황 대시보드](../src/app/staff/instructors/dashboard/page.tsx)의 "서류상태" 배지 칸에 두 가지를 추가로 표시(별도 컬럼 없이 배지 아래 텍스트로 — "구현 편한 방식" 선택):

- **누락 서류**: 정형 서류 7종(`DOC_TYPES`) 중 그 강사의 `instructor_documents`에 없는 종류를 `" · "`로 이어서 "…누락"으로 표시
- **임박/만료 D-day**: `expiring_soon`은 "D-{남은일수}", `expired`는 "만료 {지난일수}일 경과" — 서류가 여러 건이면 건별로 각각 한 줄씩

날짜 계산은 [`lib/documents.ts`](../src/lib/documents.ts)에 새로 추가한 `daysUntil()`(`computeStatus()`와 동일한 UTC 날짜 규칙, 시간대 영향 없음)로 처리 — `computeStatus()`처럼 저장된 `status` 컬럼이 아니라 `expires_at` 원본으로 매 요청마다 다시 계산해서, 며칠이 지나도 정확함.

## 2. 완료기준 검증 (실제 업로드로 브라우저 검증)

테스트 강사 1명에게 성범죄경력조회동의서(발급 2025-09-24 → 만료 2026-09-24, 임박)와 이력서(발급 2020-01-01 → 만료 2023-01-01, 만료)를 함께 업로드해 5개 항목을 한 번에 검증 후 삭제로 원복.

| # | 완료기준 | 결과 |
| :-- | :--- | :--- |
| 1 | 미제출 서류 종류가 정확히 나열됨 | ✅ 업로드한 2종 제외 나머지 5종("강사카드 · 개인정보동의서 · 신분증사본 · 통장사본 · 결격조회동의서 누락") 정확히 표시 |
| 2 | `expiring_soon` D-day 정확히 계산 | ✅ 오늘(2026-09-12) 기준 만료 2026-09-24 → "성범죄경력조회동의서 D-12" (직접 계산 검증: 정확히 12일) |
| 3 | `expired` 경과일 정확히 계산 | ✅ 만료 2023-01-01 → "이력서 만료 1350일 경과" (Node 로 별도 계산해 1350일 정확히 일치 확인) |

| 5 | 기존 #010(요약카드·필터·정보미비/계정미발급) 회귀 없음 | ✅ 이 테스트 강사가 요약카드 "서류 만료임박·만료 1명"에 정확히 반영됨, "정보 미비"·"계정 미발급" 배지도 그대로 정상 동작 |
