# 작업지시서 #019 완료보고 — 강사별 강의이력 조회 및 경력증명서 발급

- 일자: 2026-09-15
- 결과: **완료** (완료기준 7항목 전부 실제 데이터·실제 화면으로 검증)

---

## 1. 구현 내용

### 2-1. 기관 설정 — [`/staff/settings`](../src/app/staff/settings/page.tsx)
관리자 메뉴에 "기관 설정"을 추가. `org_settings`는 항상 1행만 존재하도록 `id BOOLEAN PRIMARY KEY DEFAULT true CHECK (id)`로 강제한 단일설정 테이블. 기관명·대표자명·주소 입력 폼 + 직인 이미지 업로드(비공개 `org-assets` 버킷, staff 전용)를 한 화면에서 등록. 이후 증명서 발급 시 이 값을 그대로 사용.

### 2-2. 강사별 강의이력 조회 — [`/staff/instructors/career`](../src/app/staff/instructors/career/career-client.tsx)
강사 선택 → [`getLectureHistory()`](../src/app/staff/instructors/career/actions.ts)가 `assignments`(강사 소유) → `lecture_confirmations`(완료된 강의만, #012 산출물) → `class_sessions`/`schools`/`programs` 순으로 조인해 일자순 목록 표시. 기간 필터(시작일~종료일, 비워두면 전체기간)는 `actual_date`(실제 강의일) 기준. 상단에 총 건수·총 시간 요약, 필터를 바꾸면 즉시 재계산.

### 2-3. 경력(강의)증명서 PDF 생성 — [`career-certificate-pdf.ts`](../src/lib/career-certificate-pdf.ts)
정해진 기존 양식이 없어(지시서 1. 확정 사항) `pdfkit` + `Noto Sans KR`(#014-1에서 쓴 방식 재사용)로 새로 디자인:
- 상단 기관명 + 문서번호, 중앙 제목 "경력(강의)증명서"
- 강사 인적사항(성명/생년월일) + 조회기간
- 강의이력 표(순번/일자/학교명/프로그램명/강의시간, 페이지 넘어가면 헤더 다시 그림)
- 총 강의 건수·총 강의시간 요약
- 발급일자 + 기관명·대표자명 + 직인 이미지(대표자명 옆에 삽입, 지원하지 않는 이미지 포맷이면 직인 없이 계속 진행)

문서번호는 `next_career_certificate_no()` DB 함수가 `career_certificate_counters(year, next_seq)`를 원자적 UPSERT로 증가시켜 `HEW-2026-0001` 형태로 채번(동시 발급에도 중복 없음). 생성된 PDF는 `career-certificates/<instructor_id>/<문서번호>.pdf`에 업로드하고 `career_certificate_issuances`에 강사·기간·건수·시간·문서번호·발급자·파일경로를 기록. 이력이 하나도 없으면 서버 액션이 "발급할 이력이 없습니다" 오류를 반환하고 PDF/이력 어느 것도 생성하지 않음(버튼도 비활성화로 이중 방지).

발급 이력 목록에서 과거 발급본마다 1시간 유효 서명 URL로 재다운로드 가능.

## 2. 완료기준 검증 (실제 DB·실제 화면)

김민수 강사에게 서로 다른 학교·프로그램의 완료 강의 4건(2025년 2건, 2026년 2건)을 실제로 만들어 검증한 뒤 전부 삭제(코드 변경 없는 데이터 작업).

| # | 완료기준 | 결과 |
| :-- | :--- | :--- |
| 1 | `org_settings`에 기관명·대표자명·주소·직인 이미지 등록 | ✅ 전부 입력·저장 확인, 직인 이미지 업로드 후 미리보기 정상 렌더링 |
| 2 | 강사 선택 시 강의이력이 일자순으로 정확히 조회 | ✅ 4건이 2025-03-10 → 2026-08-12 순으로 정확히 표시 |
| 3 | 기간 필터 적용 시 해당 기간만 표시 + 총 건수·시간 재계산 | ✅ 2026-01-01~ 필터 시 4건→2건, 8.5시간→5시간으로 정확히 축소 |
| 4 | "증명서 발급" 클릭 시 위 구성대로 PDF 생성 + 직인 정상 삽입 | ✅ 실제 발급해 PDF를 직접 다운로드·확인 — 기관명/문서번호/성명/생년월일(미등록)/조회기간/표/합계/발급일자/대표자명/주소 전부 정확. 직인은 pdfkit 원시 콘텐츠 스트림에서 정상 이미지 삽입 명령 확인(표 "순번" 열의 단독 숫자는 이 세션의 PDF 텍스트 추출 도구가 고립된 한 글자를 누락하는 표시 도구 한계일 뿐 — 미가공 스트림에 `[<0001> 0] TJ`로 정상 인코딩되어 있어 실제 렌더링엔 문제없음을 별도로 확인) |
| 5 | 문서번호가 중복 없이 자동 채번 | ✅ `HEW-2026-0001` → 재발급 시 `HEW-2026-0002` 자동 증가(DB UPSERT 원자적 채번) |
| 6 | 발급마다 `career_certificate_issuances`에 이력이 남고 과거 PDF 재다운로드 가능 | ✅ 같은 강사에게 2회 발급 → 발급 이력에 2건 모두 별도 행으로 남고, 각각 "다운로드" 링크로 실제 파일 재수신 확인 |
| 7 | 강의 이력이 없는 강사 선택 시 "발급할 이력이 없습니다" 안내 + 빈 문서 미생성 | ✅ 박서연(이력 0건) 선택 시 안내 문구 표시, 버튼 클릭해도 DB에 발급 이력 생성 안 됨을 직접 확인 |
