## 1. 구현 내용

### 1-1. 학교 신청 대리입력 (`/staff/requests/new`, staff 전용)
- #002 학교용 폼과 동일 항목 + **학교 선택** 드롭다운 추가 + **비고**(원 신청자·특이사항)
- 저장 시 `session_requests.submitted_by` = 관리자 `display_name`, `proxy_note` = 비고
- 마이그레이션 `20260910020000_session_request_proxy_note.sql` — `session_requests.proxy_note TEXT` 추가
- 승인 절차는 #002 그대로 재사용 (이 화면은 입력 대행만). `/staff/requests` 에 "+ 대리입력" 버튼, 상세 화면에 "대리입력 비고" 표시

### 1-2. 강사 정보 대리입력 (staff 전용)
- `/staff/instructors` — 강사별 "대리입력" 버튼 + "계정 없이 강사 등록 (대리입력)"
- `/staff/instructors/new-profile` — 계정·초대 없이 `instructors` row 만 생성 (계정 발급은 #003-1 로 별도)
- `/staff/instructors/[id]/edit` — 기본정보 + 학력/경력(다건) + 자격증(다건) + 전문분야(태그)를 **한 폼**에서 입력, **저장** 버튼 하나로 반영 (경력/자격증/전문분야는 전체 교체)
- 사진·제출서류는 기존 `/instructor`·`/instructor/documents` 화면을 **대리입력 모드**로 재사용:
  - `auth.ts` 에 `PROXY_INSTRUCTOR_COOKIE` 추가 → staff 가 이 쿠키를 가지면 `getInstructorContext().readOnly=false, proxy=true`
  - `/instructor` 레이아웃에 파란 배너 + "강사 목록" 네비
  - 서류 업로드는 storage 의 staff 정책(#003)으로 그대로 동작

### 1-3. AI 자동채움 공통 기능
- **`src/lib/hwp.ts`** — 한글 문서 텍스트 추출 (서버 전용)
  - `.hwpx` → ZIP(fflate) + `Contents/sectionN.xml` 의 `<hp:t>` 텍스트
  - `.hwp` (HWP 5.x OLE) → `hwp.js` 파싱 → 문단/표 텍스트
- **`src/lib/ai-autofill.ts`** — `autofillFromFile(kind, buffer, filename, mime)`
  - hwp/hwpx → 텍스트 추출 → Claude 에 텍스트 전달
  - 이미지(jpg/png/webp) → base64 image 블록으로 Claude 에 전달 (비전)
  - 대상 화면별 JSON 스키마(학교신청 / 강사)로 값 추출 요청 → JSON 파싱
  - **민감정보 금지**: system 프롬프트에서 주민등록번호·계좌번호 등 추출 금지 명시, 스키마에도 없음
  - 모델 `claude-opus-5` (`ANTHROPIC_MODEL` 로 재정의 가능, 예: `claude-sonnet-5`)
  - `ANTHROPIC_API_KEY` 없으면 → `AI_AUTOFILL_MOCK=1` 일 때만 모의 추출, 아니면 명확한 안내 에러
- **`/api/ai/autofill`** (route, staff 인증) — multipart 업로드 → 추출 결과 JSON
- **`src/components/autofill-panel.tsx`** — 두 대리입력 폼 공용. 파일 업로드 → `onFilled(fields)` → 폼 state 에만 반영 (DB 저장은 관리자가 별도 버튼)
- 자동채움 결과는 학교/프로그램은 이름 근사 매칭으로 드롭다운 선택, 나머지는 입력값으로 채움. 못 읽은 항목은 빈칸

## 4. 발견 / 판단

- **강사 대리입력 화면**: #003 의 4개 섹션 컴포넌트는 각각 개별 저장 구조라 자동채움("저장 전 미반영")과 안 맞아, staff 전용 **통합 단일 폼**(`[id]/edit`)을 별도로 만들고 경력/자격증/전문분야는 전체 교체 방식으로 저장. 사진·서류는 기존 화면을 대리입력 모드로 재사용.
- **hwp vs hwpx**: 둘 다 지원. hwpx(ZIP+XML)가 안정적이고, hwp(OLE)는 `hwp.js` 로 표까지 텍스트 추출 확인. 엑셀/워드/PDF 는 범위 제외.
- **비고란**: `session_requests` 에 `proxy_note` 컬럼 추가(스키마 변경 최소). 담당자 이메일처럼 별도 저장 안 함.
- **민감정보**: 프롬프트 금지 + 스키마 미포함 두 겹으로 차단. 실제 Claude 호출에서 주민번호·계좌번호가 문서에 있어도 추출되지 않음을 확인.
