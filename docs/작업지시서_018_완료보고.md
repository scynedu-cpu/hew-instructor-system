## 1. 구현 내용

### 랜딩 화면 지정 — [`auth.ts`](../src/lib/auth.ts)

`roleHome("staff")`를 `/staff/requests` → **`/staff`**로 변경. 로그인 직후·`requireRole` 실패 시 되돌아가는 곳 등 staff 관련 모든 리다이렉트가 이 함수 하나를 거치므로, 이 한 줄 변경만으로 로그인 후 첫 화면이 모니터링 대시보드가 됨. 상단 메뉴에도 "오늘의 현황"을 첫 항목으로 추가([`layout.tsx`](../src/app/staff/layout.tsx)).

### 화면 — [`page.tsx`](../src/app/staff/page.tsx)(데이터) + [`ops-dashboard.tsx`](../src/app/staff/ops-dashboard.tsx)(표시)

승인된 목업(`ops_monitor_mockup.jsx`)의 레이아웃·톤·차트 구성을 그대로 따르되, 모든 수치를 실데이터로 계산하도록 데이터 조회/계산(`page.tsx`, 서버 컴포넌트)과 프레젠테이션(`ops-dashboard.tsx`, `lucide-react` + `recharts` 신규 설치)을 분리했다.

**"지금 처리해야 할 일"** — 지시서 2-2 기준 그대로 4유형을 실데이터로 계산:
- 최종확정 기한 초과: 기존 `assignments_pending_final_confirm()` RPC 재사용(#004와 동일 기준으로 통일)
- 강의완료 처리 누락: `session_status='confirmed' AND scheduled_date < 오늘`인 세션 중 배정에 `lecture_confirmations`가 없는 건
- 강사 미배정 세션: `session_status='unassigned'`이고 `scheduled_date`가 14일 이내인 건
- 평판 급락 감지: 강사별 최근 5건 vs 직전 5건 만족도 평균 하락폭 0.8점 이상(강사마다 개별 카드로 표시, 없으면 0건)
- 각 카드의 액션 버튼은 실제 라우트로 링크(`<Link>`) — "완료 처리하기"는 캘린더에 새로 추가한 `?y=&m=&sessionId=` 딥링크로 해당 세션 상세 패널을 바로 연다([`calendar/page.tsx`](../src/app/staff/calendar/page.tsx), [`calendar-client.tsx`](../src/app/staff/calendar/calendar-client.tsx) 수정).
- 처리할 일이 0건이면 "🎉 지금 처리할 일이 없습니다." 안내로 대체(지시서 4. 완료기준 마지막 항목).

**전체 상태 배너 + 영역별 신호등** — 지시서 2-3 판정 기준 그대로:
- 다가오는 일정: 완료처리 누락 존재→빨강 / 미배정(임박) 존재→노랑 / 없음→초록
- 강사 관리: 서류 `expired` 존재→빨강 / `expiring_soon`·정보미비·계정미발급 존재→노랑 / 없음→초록 (#010 대시보드와 동일한 계산 로직 재사용)
- 정산: `payment_rate_settings` 자체가 없음→빨강 / 미지급 중 정산일로부터 30일 경과 건 존재→노랑 / 그 외 초록
- 만족도설문: 설문 QR을 보낸(=`survey_links` 존재) 세션 중 응답 0건 존재→노랑 / 그 외 초록(빨강 없음)
- 전체 배너 = 네 영역 중 하나라도 빨강이면 빨강, 아니면 하나라도 노랑이면 노랑, 전부 초록이면 초록

**차트** — 지시서 2-4 그대로:
- 만족도 추이(라인차트): 최근 6주, 주차별로 그 주에 제출된 `question_type='rating_5'` 문항 응답 **전체**의 평균 점수(강사평가 문항 1개 + 공통/그룹별 문항 전부 포함)
- 세션 상태 분포(막대차트): 현재 학년도(`academic_year`) `class_sessions`를 상태별(미배정/임시배정/확정/완료)로 카운트

**영역별 카드 바로가기** — 지시서 2-5 그대로 4개 화면으로 연결(강사 관리→`/staff/instructors/dashboard`, 다가오는 일정→`/staff/calendar`, 정산→`/staff/payments`, 만족도설문→`/staff/survey-results`).

### 범위 제외(지시서 3. 그대로)
5분 자동 폴링 없음(진입/새로고침 시에만 재계산), 신호등 임계치는 코드에 고정값으로 반영(화면에서 조정 불가).
