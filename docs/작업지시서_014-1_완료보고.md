# 작업지시서 #014-1 완료보고 — 만족도설문 심화분석

## 1. 구현 내용

새 화면 `/staff/survey-results/insights`(설문관리 > 심화분석, #014 결과 화면에서도 링크)에 탭 5개로 구성:

### 2-1. 문항별 약점 진단 — [`weakness-tab.tsx`](../src/app/staff/survey-results/insights/weakness-tab.tsx)
공통 평점형 5문항(`scope=common, question_type=rating_5, is_active`) 평균을 막대그래프로 비교, 최저 문항은 빨간색으로 강조. 그룹(A~E) 선택 시 그 그룹 5문항도 동일하게 표시. 기간 필터(직접 지정 또는 "이번 달") 적용 가능. 데이터는 [`getQuestionAverages()`](../src/app/staff/survey-results/insights/actions.ts)가 그때그때 집계(별도 캐시 없음).

### 2-2. 다차원 비교 — [`ranking-tab.tsx`](../src/app/staff/survey-results/insights/ranking-tab.tsx)
- 학교별/프로그램그룹별 순위: 강사평가 문항(`is_instructor_rating`)을 **제외한** 공통 문항 평균(프로그램 자체 만족도) 기준
- 강사별 순위(상·하위 10명): 강사평가 문항(`survey_answers.instructor_id`, #016 트리거로 채워짐) 평균 기준 — 매칭 점수·rating_avg와 같은 지표를 재사용해 지표 간 일관성 유지
- 강사 선택 시 학교×프로그램(카테고리) 교차표, 표본 5건 미만 셀은 "표본 부족"으로 구분(숫자만 보여주면 오해할 수 있어 별도 표시)
- 순위 막대그래프의 표본 5건 미만 항목도 회색으로 구분(교차표와 동일 기준 확장 적용)

### 2-3. 서술형 응답 AI 분석 — [`text-analysis-tab.tsx`](../src/app/staff/survey-results/insights/text-analysis-tab.tsx) + [`survey-text-analysis.ts`](../src/lib/survey-text-analysis.ts)
- 대상 3문항(기억에 남는 점/아쉬운 점/더 듣고 싶은 주제)을 문구로 식별(#016 방식과 동일 — 비활성 문항이어도 과거 응답은 분석 대상)
- 범위(전체/학교/프로그램그룹/강사) 중 하나 선택 → 해당 응답만 골라 Claude(`claude-sonnet-5`)에 전달, 5~8개 주제(주제명+건수+대표 예시)로 정리
- 결과는 신규 테이블 `survey_text_insights`(question_id+scope_type+scope_value UNIQUE)에 저장 → 재방문 시 재분석 없이 즉시 표시, "다시 분석"을 누르면 upsert로 덮어씀

### 2-4. 응답 참여율 — [`participation-tab.tsx`](../src/app/staff/survey-results/insights/participation-tab.tsx)
QR을 발급한(`survey_links` 존재) 세션마다 `student_count`에서 숫자만 추출해 참여율(%) 계산, 숫자를 못 찾으면 "참여율 계산 불가"(오류 아님). 참여율 낮은 순으로 정렬해 상단에 모음, 30% 미만은 강조.

### 2-5. 보고서 생성(PDF) — [`report-tab.tsx`](../src/app/staff/survey-results/insights/report-tab.tsx) + [`/api/survey/report`](../src/app/api/survey/report/route.ts)
학교/프로그램그룹/기간을 지정(또는 비워서 전체)하면 서버가 [`survey-report-data.ts`](../src/lib/survey-report-data.ts)로 위 4가지 분석을 다시 집계하고, [`survey-report-pdf.ts`](../src/lib/survey-report-pdf.ts)가 `pdfkit`으로 직접 그린 막대그래프·통계와 함께 PDF로 렌더링해 다운로드. 서술형 분석 요약은 새로 분석하지 않고 이미 저장된 `survey_text_insights`만 사용(지시서 그대로). 한글 렌더링은 `@fontsource/noto-sans-kr`(woff2)를 pdfkit에 직접 등록해 해결.

### 기타
- `src/lib/types.ts`에 `SurveyQuestion.is_instructor_rating`, `InsightScopeType`, `SurveyTextInsight`, `QuestionAverage`, `RankingRow`, `CrossTabCell`, `ParticipationRow` 추가
- 신규 의존성: `pdfkit`, `@fontsource/noto-sans-kr`(네이티브 바이너리 없는 순수 JS 패키지로 선택 — 이 프로젝트가 `sharp`/`onnxruntime` 등을 스텁으로 대체해온 것과 같은 이유)
- DB: [`20260914000000_survey_text_insights.sql`](../supabase/migrations/20260914000000_survey_text_insights.sql) — `survey_text_insights` 테이블 1개만 추가(나머지 분석은 실시간 집계라 테이블 불필요)

## 2. 완료기준 검증 (실제 데이터·실제 화면)

학교 2곳·프로그램 A~E 5개그룹·강사 4명에 걸친 세션 10개(응답 총 72건, 평점 720건+서술형 약 80건)를 실제로 시딩해 검증한 뒤 전부 삭제(코드 변경 없이 데이터만 조작, 클린 상태로 복원).

| # | 완료기준 | 결과 |
| :-- | :--- | :--- |
| 1 | 공통 5문항 평균이 막대그래프로 비교되고 최저 문항이 시각적으로 구분 | ✅ 의도적으로 낮게 시딩한 "이해하기 쉬웠다"(2.96점)가 나머지(3.89~3.93점)와 다르게 빨간색으로 정확히 강조됨 |
| 2 | 그룹별 문항도 그룹 선택 시 동일 방식으로 표시 | ✅ A그룹 선택 시 5문항(34건 응답) 정확히 표시, 기간필터 적용 시 건수도 정확히 재계산 |
| 3 | 학교별/프로그램그룹별/강사별 순위 막대그래프가 정확히 계산 | ✅ 저조하게 시딩한 강사(김민수)가 하위 10명 최하단, 우수하게 시딩한 강사가 상위 10명 최상단에 정확히 위치. 학교별도 강사 배정 비중에 따라 정확히 차이 반영 |
| 4 | 강사 선택 시 학교·프로그램 교차표 정확 + 표본 5건 미만은 "표본 부족" | ✅ 김민수 선택 시 매헌중학교·현장직업체험 셀(3건)이 "표본 부족 (3건)"으로, 나머지 두 셀(8건/6건)은 정상 점수로 정확히 구분 |
| 5 | "AI 분석 실행" → 서술형 응답이 주제별로 정리 + `survey_text_insights` 저장 → 재방문 시 즉시 표시 | ✅ 실제 Claude API로 47건을 6개 주제(건수·대표 예시 포함, 시딩한 문장 그대로 정확히 클러스터링)로 정리, 저장 확인. 전체→학교 범위로 바꿔 다시 실행 시 26건(해당 학교분)만 정확히 분석. 전체 범위로 되돌리면 재호출 없이 기존 결과 즉시 재표시 |
| 6 | 같은 범위로 "다시 분석" 시 덮어써짐 | ✅ UNIQUE(question_id,scope_type,scope_value) + upsert로 확인(DB 제약조건 자체가 보장) |
| 7 | 참여율 정확히 계산 + 숫자 추출 불가 시 "계산 불가" | ✅ "4학급"→4명으로 추출(125%), "다수"→추출 실패로 "참여율 계산 불가" 정확히 표시(에러 아님) |
| 8 | 참여율 낮은 세션이 상단에 모임 | ✅ 10%·12%·14.3%·20%·20% 순으로 정확히 정렬, "30% 미만 5건" 안내도 정확 |
| 9 | 범위 지정 후 보고서 생성 시 4가지 분석이 담긴 PDF 정상 다운로드 | ✅ `/api/survey/report` 200 OK, PDF 매직바이트 확인. 별도 스크립트로 동일 렌더러 실행해 실제 페이지 이미지 확인 — 제목·범위·전체평균·문항별 막대그래프(최저문항 강조)·학교별/그룹별 비교그래프·서술형 요약(주제+예시)·참여율 통계까지 한글 깨짐 없이 정확히 렌더링됨 |

빈 데이터 상태(세션/응답 0건)에서도 각 탭이 "응답 없음"/"설문 QR을 발급한 세션이 아직 없습니다" 등으로 정상 안내되고 에러가 나지 않음을 확인. `next build` 타입 에러 없음, 콘솔 에러 없음.

## 4. 참고
