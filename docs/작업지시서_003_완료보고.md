## 1. 구현 내용 (`instructor` role)

`/instructor` (기본 정보) · `/instructor/documents` (제출 서류) 2개 탭.

### 기본 프로필 (`instructors`) — `/instructor`
- 사진 / 성명* / 생년월일 / 주소 / 자택전화 / 휴대전화* / 이메일 / 계좌 조회·수정
- **계좌번호 마스킹**: 평소엔 뒤 4자리만(`••••1234`), "수정" 누르면 전체 입력창
- **사진 업로드**: `instructor-photos` 버킷(공개) `<id>/photo-*.png` → `photo_url` 에 공개 URL 기록
- 필수(성명·휴대전화) 미입력 시 "프로필 저장" 비활성 + 안내

### 경력 / 자격증 (`instructor_career_history`, `instructor_certifications`) — 다건
- 공통 `EditableList` 컴포넌트: 행별 인라인 수정/삭제 + 하단 추가 폼
- 경력: 연월 / 내용* / 발령청·기타
- 자격증: 자격증명* / 취득일 / 발급기관

### 전문분야 (`instructor_specialties`) — 태그
- 칩(chip) + × 삭제, 입력창 Enter/추가, 자유입력 + `datalist` 자동완성(AI교육·드론전문가 등)
- 중복 추가 방지

### 제출 서류 (`instructor_documents`) — `/instructor/documents`
- 7종(강사카드/개인정보동의서/신분증사본/통장사본/결격조회동의서/성범죄경력조회동의서/이력서) 종류별 1건
- 파일 → `instructor-documents` 버킷(비공개) `<id>/<uuid>-<파일명>` 업로드, `file_url` 에 **경로** 기록
- 화면에서는 1시간짜리 **서명 URL**("파일 보기")로 열람
- **만료일 자동계산** (DB 트리거 `instructor_documents_set_expiry`):
  - 성범죄경력조회동의서 → `issued_at + 1년`
  - 이력서 → `issued_at + 3년`
  - 그 외 → 만료 없음(`expires_at` NULL, `status='valid'`)
- **상태 자동판정**: `오늘 >= 만료` → 만료 / `만료 - 30일 <= 오늘` → 임박 / 그 외 → 정상
  - DB 트리거가 저장 시 `status` 계산 + 화면은 항상 "오늘" 기준으로 재판정(표시값·기준일 항상 일치)
- 서류별 상태 배지(정상/임박/만료), 임박·만료 서류는 재업로드 버튼이 주황색으로 강조

## 4. 발견/보완

- **Storage "Invalid key"**: 객체 경로에 한글(`doc_type`)을 넣으니 거부됨 → 경로를 `<id>/<uuid>-<ascii파일명>` 으로 변경, 파일명도 ASCII 로 치환.
- **만료일 하루 오차**: TS `new Date("YYYY-MM-DD")` 가 로컬(KST) 파싱되어 UTC 변환 시 -1일. → 만료일 계산을 DB 트리거로 이관(단일 소스), TS 함수는 UTC 고정으로 수정(미리보기용).
